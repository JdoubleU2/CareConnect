# CareConnect Architecture Documentation

This directory contains the architecture documentation for the CareConnect project. The documentation is split into different files for better organization and maintainability.

## Documentation Structure

### 1. Layered Architecture (`layered.md`)
- Shows the system's layered architecture
- Describes each layer's components and responsibilities
- Illustrates the relationships between layers

### 2. Class Diagram (`class.md`)
- Displays the system's class structure
- Shows relationships between components
- Details the attributes and methods of each class

### 3. Data Flow Diagram (`dataflow.md`)
- Illustrates how data moves through the system
- Shows the training and deployment workflows
- Details the data transformation steps

## How to Use These Diagrams

These diagrams are written in PlantUML format. To view them, you can:

1. Use the [PlantUML Online Editor](https://www.plantuml.com/plantuml/uml/)
2. Install a PlantUML plugin in your IDE (VS Code, IntelliJ, etc.)
3. Use a tool like [Mermaid](https://mermaid.live/) (though you'll need to convert the syntax)

## Maintaining the Documentation

When making changes to the system architecture:

1. Update the relevant diagram(s)
2. Keep the documentation in sync with the actual implementation
3. Add new components and relationships as they are developed
4. Remove deprecated components and relationships
